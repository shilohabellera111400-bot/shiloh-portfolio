Designed to match the bold crimson & dark modern aesthetic requested by the course requirements, featuring interactive multi-view project showcases, academic milestones & achievements, numbered toolkit skills, and 5-stage work process.

## 🌐 Deploying to Vercel via GitHub (Professor Requirement)

### Step 1: Create a GitHub Repository
1. Visit [github.com/new](https://github.com/new).
2. Set repository name to `shiloh-portfolio`.
3. Set visibility to **Public**.
4. Click **Create repository**.

### Step 2: Push your code
In PowerShell inside this project folder:
```bash
git add .
git commit -m "feat: complete modern portfolio with achievements and projects"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/shiloh-portfolio.git
git push -u origin main
```

### Step 3: Connect and Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and click **Log in with GitHub**.
2. Click **Add New... → Project**.
3. Choose `shiloh-portfolio` and click **Import**.
4. Click **Deploy**. Within 60 seconds, your portfolio is live worldwide with free HTTPS!
